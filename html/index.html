sharedwatch

Calm, durable, pull-based activity feed for a local shared folder.

MIT Go 1.22+ single binary SQLite-backed

A single Go binary that watches a folder on disk, captures every change into a SQLite-backed queue, and lets you review the activity on your own cadence — every 5–10 minutes by default, near-real-time on demand. The watcher never interrupts you; you pull a digest when you're ready.

Install

curl -fsSL https://raw.githubusercontent.com/ab0t/sharedwatch/main/scripts/install.sh | bash

Or grab a tagged release tarball from the releases page.

60-second quickstart

sharedwatch init
sharedwatch run &
echo "hello" > ~/.local/share/sharedwatch/watch/hello.md
sharedwatch digest list

What it's for

  • A single host where a human (or assistant agent) wants ambient awareness of a folder without being interrupted.
  • Low-to-moderate write volume, restart-safe operation with a durable on-disk queue.
  • Multi-folder watching with stable labels (--root auth=/path, --root billing=/path).
  • Progressive disclosure: overview → stats → full event list, so consumers fetch only what they need.

What it's not

  • Not a git replacement — this records that a file changed, not byte-level content history.
  • Not a multi-host file share or sync service.
  • Not push-based — consumers pull on their own cadence.
