## Section 3 — JSON-structured errors

- [x] **S3.1.** Add `fatalJSON(jsonMode bool, code, msg string, args ...any)` helper.
      Touches: `src/cmd/sharedwatch/main.go` (alongside the existing `fatal`).
      Verify: with `jsonMode=true`, emits `{"format_version":1,"error":{"code":...,"message":...}}` on stdout and exits 1.

- [x] **S3.2.** Wire `fatalJSON` into the handlers that take `--format`: `events list`, `events stats`, `sql`, `schema`, `overview`.
      Touches: those handlers.
      Verify: bad input on `events list --format json --since not-a-time` produces the JSON envelope on stdout (not text on stderr).

- [x] **S3.3.** Define the small error-code vocabulary (`bad_flag` / `not_found` / `permission` / `db_error` / `network_error` / `internal`) at the top of the file in a const block.
      Touches: `src/cmd/sharedwatch/main.go`.
      Verify: each handler calls `fatalJSON` with one of these codes; no inline string literals.
