## Section 1 — Wider `fatalJSON` coverage

- [x] **S1.1.** `events stats` — add `jsonErr := isJSONFormat(*formatFlag)` after Parse; convert all user-facing `fatal()` to `fatalJSON(jsonErr, code, msg)`.
      Touches: `src/cmd/sharedwatch/main.go` (`handleEventsStats`).
      Verify: `events stats --root nope --format jsonl` returns a JSON envelope on stdout.

- [x] **S1.2.** `sql` — same pattern. Errors include: SELECT/WITH/EXPLAIN parsing failures, `--write` denial on mutation, file-not-found on `--file`.
      Touches: `src/cmd/sharedwatch/main.go` (`handleSQL`).
      Verify: `sql "garbage" --format jsonl` returns JSON envelope; `sql "UPDATE x" --format jsonl` returns JSON envelope with code `bad_flag` (write denied is a usage-style error).

- [x] **S1.3.** `schema` — same pattern. Errors: DB query failure, unknown table.
      Touches: `src/cmd/sharedwatch/main.go` (`handleSchema`).
      Verify: `schema unknown_table --format jsonl` → JSON envelope.

- [x] **S1.4.** `overview` — same pattern. Errors: aggregation failure, bad `--since`.
      Touches: `src/cmd/sharedwatch/main.go` (`handleOverview`).

## Section 2 — New dogfood scenarios

- [x] **S2.1.** Scenario 21 — "first-session canonical workflow with env vars". Single agent exports `SHAREDWATCH_*` once, never types those flags again. Walks init → emit → cursor read → roots → config show → stop. Confirms the v0.0.5 ergonomics promise.
      Touches: `docs/dogfood/test_dogfood.md`.
      Verify: scenario block matches the existing format.

- [x] **S2.2.** Scenario 22 — "stale lock file recovery". Daemon SIGKILLed leaves a stale lock; verify `stop` reports it, manual remove + `run` restart works, AND the new daemon detects nothing dangling.
      Touches: same.
      Verify: scenario block + expected outputs documented.

- [x] **S2.3.** Scenario 23 — "misbehaving agent error handling". Bad inputs across the format-aware handlers: bad `--since`, bad SQL, unknown digest ID, `--since` ↔ `--since-cursor` mutex violation. Side-by-side: text mode → stderr; JSON mode → stdout envelope.
      Touches: same.
      Verify: scenario covers each error type.

- [x] **S2.4.** Scenario 24 — "multi-agent lease warning". Actor A acquires lease; actor B writes inside the lease's path-glob; watcher logs a structured warning that B can see via journal / sql.
      Touches: same.
      Verify: scenario block.
