      Touches: `internal/db/db.go` `migrate()`.
      Verify: `sharedwatch schema events --format json` shows the new index; `EXPLAIN QUERY PLAN` on the lookup uses it.

- [x] **S2.3.** Add a focused regression test mirroring dogfood scenario 17 to `internal/db/coalesce_actor_test.go`.

- [x] **S2.4.** Update `Skills/sharedwatch-client/references/gotchas.md` §1 (coalesce subtleties) to remove the "actor-aware coalesce is a known limitation" caveat once shipped.
      Touches: `Skills/sharedwatch-client/references/gotchas.md`.
