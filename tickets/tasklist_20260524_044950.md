Target release: `v0.0.5`

End-state when this list is fully `[x]`: `sharedwatch v0.0.5` shipped via the in-repo release flow. Agents can `export SHAREDWATCH_ACTOR=… SHAREDWATCH_FORMAT=jsonl SHAREDWATCH_HINTS=agent` once at session start and not type those flags again. `sharedwatch config show` echoes the resolved defaults + their sources. `sharedwatch stop` cleanly terminates a running daemon. Config files are discovered from `$XDG_CONFIG_HOME/sharedwatch/config.yaml` in addition to the project-local default.
